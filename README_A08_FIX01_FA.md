# مدرسه‌یار معلم | A08-FIX01 — رفع خطای PersianCalendar در GitHub

## علت خطای ارسالی
در عکس GitHub، وظیفه app:compileDebugJavaWithJavac با ۱۵ خطا متوقف شده است.
سورس A08 از android.icu.util.PersianCalendar استفاده می‌کرد؛ این کلاس در SDK کامپایل اندروید قابل دسترسی نیست.
۱۵ ارجاع به همین نام در MainActivity وجود داشت. آنها با مبدل مستقل و آزمایش‌پذیر JalaliDates جایگزین شدند.

## نصب سریع (فقط اگر GitHub اکنون دقیقاً A08 است)
۱. محتوای INSTALL را در ریشه مخزن GitHub بارگذاری و مسیر فایل‌ها را حفظ کنید.
۲. اگر از Upload files استفاده می‌کنید، مطمئن شوید فایل JalaliDates.java در کنار MainActivity.java قرار گرفته است.
۳. Commit changes و سپس Actions → Build Native Teacher Android APK → Run workflow.
۴. APK خروجی پس از موفقیت از Artifacts با نام Madreseyar-Teacher-A08-FIX01-Native-Debug-APK دانلود شود.

## فایل‌ها
- MainActivity.java: حذف وابستگی به PersianCalendar و فراخوانی JalaliDates.
- JalaliDates.java: تبدیل دقیق تاریخ شمسی↔میلادی برای فرم تکالیف، بدون کتابخانه خارجی.
- app/build.gradle: نسخه‌کد از ۱۱ به ۱۲ افزایش یافت، تا نصب نسخه جدید روی قبلی ممکن باشد (با همان امضا).
- GitHub Actions: تست جدید تاریخ‌ها و نام خروجی اصلاح شد.
- TestJalaliDates.java و verify_a08.py: تست‌های مستقل و بررسی ارجاعات.
